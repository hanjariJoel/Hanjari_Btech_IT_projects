# Hanjari's Music House Stock Maintenance System

## Project Description

Hanjari's Music House Stock Maintenance System (HMH-SMS) is a
web-based inventory management system designed to help Hanjari's
Music House manage musical instruments, stock transactions,
suppliers, categories, reports, and system users.

## Features

- User authentication
- Administrator and Storekeeper roles
- Instrument management
- Category management
- Supplier management
- Stock In
- Stock Out
- Low-stock monitoring
- Inventory reports
- Stock history
- User management
- Profile management
- Password management
- Dashboard statistics
- Form validation
- Responsive interface

## Database

Database name:

hanjari_music_house_db

## Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into:

   C:\xampp\htdocs\hanjari_music_house

4. Open phpMyAdmin.
5. Create the database:

   hanjari_music_house_db

6. Import the supplied SQL database file.
7. Verify the database configuration in:

   config/database.php

8. Open the application in a browser:

   http://localhost/hanjari_music_house/

## User Roles

### Administrator

The administrator has access to system administration
features including User Management.

### Storekeeper

Storekeepers can perform normal stock maintenance operations
but do not have administrator-level user-management privileges.
